# Rishii Kumar Singh Portfolio

A recruiter-focused portfolio for Rishii Kumar Singh, an AI/ML engineer and undergraduate researcher at Delhi Technological University.

## Live site

[portfolio-rishii.vercel.app](https://portfolio-rishii.vercel.app/)

## What the site highlights

- Measured AI/ML work at WESEE, Indian Navy
- Supervised undergraduate research at AIMS-DTU
- Top 4% performance in GirlScript Summer of Code 2026
- Multi-agent orchestration, offline multilingual retrieval, grounded RAG, and multimodal computer vision projects
- A downloadable one-page resume and direct contact paths

## Stack

- React 19 and TypeScript
- Vite 8
- Tailwind CSS 4
- Framer Motion
- Lenis
- Lucide React
- shadcn/ui primitives

## Local development

```bash
npm install
npm run dev
```

The Vite development server runs at `http://localhost:5173` by default.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist`.

## Content updates

Primary portfolio content lives in `src/app/page.tsx`. Global design rules live in `src/app/globals.css`. The social preview image is `public/og.png`, and the downloadable resume is `public/resume.pdf`.
